Panel Modules

ADMIN — 14 Modules

  • Dashboard — Platform-wide stats
  • Categories — Create/edit product categories
  • Merchants — Add/manage reseller accounts
  • Cards — Create membership/loyalty cards
  • Clients — All platform customers
  • Vouchers — Discount vouchers (%, fixed)
  • Coupons — Coupon codes with category targeting
  • Items — Product catalog (CRUD + images)
  • Payments — All transactions
  • Bookings & Tickets — Service bookings
  • Orders — All user orders
  • Reports — Reseller, Payment, Membership
  • Audit Trail — Activity log (who did what)
  • Feedback/Complaints — Resolve issues

MERCHANT — 9 Modules

  • Dashboard — Own store stats
  • Stores — Add/edit physical locations
  • Clients — Own walk-in customers
  • Items — View product catalog (read-only)
  • Billing — Record sales transactions
  • Cards — View assigned membership cards
  • Redemption — Process point/voucher redemptions
  • Reports — Sales, Payment Mode, Settlement, Cashback
  • Feedback — Raise complaints, view feedbacks

STORE — 8 Pages + 6 Account Tabs Complete

  • Homepage — Hero banner, categories, featured products, promos
  • Catalog — Category filter sidebar, search, product grid, add to cart
  • Product Detail — Image, pricing, stock, quantity selector, add to cart
  • Cart — Quantity controls, coupon input, order summary, proceed to checkout
  • Checkout — Address form, payment mode (COD/UPI/Card/NetBanking), place order
  • Account — 6 tabs: Profile, Orders, Card, Wallet, Plus, Referral
  • Wishlist — Saved items with add to cart action
  • Abhie Plus — Premium membership landing (benefits, testimonials, CTA)

Account Tab Details

  • Profile — User info, edit details
  • Orders — Order history with status
  • Card — Loyalty card (visual gradient card, card number, cardholder)
  • Wallet — Spend tracking, points earned/redeemed (1pt per ₹25, min 100 to redeem)
  • Plus — Membership status, savings, benefits (or upgrade CTA)
  • Referral — Refer & earn (code, link, history, stats)

Authentication Flow

User visits /login
    │
    ├── Tab 1: Email + Password
    │       └── Supabase signInWithPassword()
    │
    └── Tab 2: Phone + OTP
            ├── Send OTP → Supabase signInWithOtp()
            └── Verify OTP → Supabase verifyOtp()
    │
    ▼
Auth successful → fetch profiles.role
    │
    ├── role = 'admin'    → redirect to /admin
    ├── role = 'merchant' → redirect to /merchant
    └── role = 'client'   → redirect to /store (Phase 3)

Real-World Example Flow

  1. Admin creates merchant "Vikash" with email vikash@store.com
  2. Admin creates items (HP Laptop ₹61,493, iPhone ₹79,999)
  3. Admin creates voucher "FLAT20" — 20% off, max ₹500
  4. Admin creates Gold Card and assigns to Vikash's store
  5. Vikash logs in → sees Merchant Dashboard
  6. Vikash adds his store "Vikash Electronics, Jamshedpur"
  7. Vikash adds client "Rahul" (walk-in customer)
  8. Vikash creates billing: ₹61,493 via UPI for HP Laptop
  9. Vikash processes redemption: Rahul redeems 500 points = ₹50 off
  10. Vikash checks Reports → sees monthly sales & settlement
  11. Admin views Audit Trail → confirms all transactions
  12. Admin processes Settlement → pays Vikash his commission

Setup Instructions

1. Create Supabase Project

Go to supabase.com → New Project → Copy URL and anon key

2. Run Database Migration

Open Supabase SQL Editor → Paste contents of supabase/migration.sql → Run

3. Update Environment Variables

Edit .env.local:

VITE_SUPABASE_URL=https://your-project.supabase.co
VITE_SUPABASE_ANON_KEY=eyJhbGciOi...

4. Create Admin User

Sign up via the app → In Supabase dashboard, set profiles.role = 'admin' for that user

5. Run Dev Server

cd abhie-platform
npm run dev    → http://localhost:5178
